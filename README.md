# game-of-life

Adapted [source](https://johnhw.github.io/hashlife/index.md.html)

Run `cargo run` and you are done.

## Controls

- **W**: Move the camera upwards
- **A**: Move the camera to the left
- **S**: Move the camera downwards
- **D**: Move the camera to the right
- **I**: Zoom-in
- **O**: Zoom-out
- **P**: Pause
- **E**: Advance the game 2\*\*k generations ahead. Can only be done when the game is paused
- **G**: Display the grid in which the squares are rendered
